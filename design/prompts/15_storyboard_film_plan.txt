다음 디자인 가이드를 따라 콘티 · 연출 기획서를 HTML로 만들어 줘.

가이드 = 함께 붙여넣은 "Storyboard · Film Plan" 디자인 가이드 참조.

[주제]
예: "단편 애니메이션 콘티" / "광고 30초 연출 기획" / "트레일러 콘티"

[작품 정보 — 표지 슬레이트에 들어감]
- 제목 / 포맷 (2D·3D·실사 · 비율 · 해상도) / 러닝타임 / 씬 수 · 컷 수 / 감독

[내용 — 있는 만큼만]
- 씬 리스트: 씬번호 - 장소 - 시간대 - 컷수 - 길이 - 그 씬의 핵심
- 콘티 낼 씬 하나 고르기: 컷별로
  · 컷 번호 / 앵글(WIDE·CLOSE·O.S.·PAN·TWO SHOT 등) / 초수 / 무엇을 보여주는지 한 줄
  · 화면 구도 (인물 몇 명, 어디에, 시선·이동 방향, 강조 대상)
- 컷 상세 1개: 길이 · 렌즈 · 카메라 무브 · 조명 · 사운드 · 주의사항

[요구]
- 라이트 워크시트 톤 (#F4F4F2 배경 · 흰 카드 · #D9D9D4 테두리)
- 액센트 #2F6B63 는 **숫자에만** (초수 · 컷수). 문장에는 쓰지 말 것
- 번호·시간·렌즈·라벨 = JetBrains Mono 대문자 자간 넓게 / 본문 = Pretendard
- 표지 = 큰 제목 + 오른쪽 검정 슬레이트(위 흑백 교차 줄무늬 6칸 + 메타 행, 숫자만 민트 #7FD1C5)
- 씬 리스트 표 + 아래 요약 3칸 (총 컷수 · 러닝타임 · 로케이션)
- 콘티 시트 = 3열 그리드, 각 칸 = 16:9 프레임(좌상단 검정 컷번호 배지) + 앵글·초수 + 한 줄 설명
- **프레임 안은 그림 X, 도형으로 구도만**:
  상하 2분할 + 지평선 1px / 인물 = 위가 둥근 세로 막대(크기=원근, opacity=앞뒤)
  / 이동·시선 = 액센트 선 + 삼각 화살촉 / 강조 = 액센트 테두리 사각
- 컷 상세 = 왼쪽 큰 프레임 + 오른쪽 스펙 시트 (LENGTH·LENS·MOVE·LIGHT·SOUND·NOTE)
- 설명은 지시문으로. 감정 형용사("아름답게·감동적으로") 금지 — 카메라·빛·소리로 적을 것
- 다크 배경 X · 이모지 X · 그림자 X · 둥근 모서리 X
