다음 디자인 가이드를 따라 전통문화 제안 PPT를 HTML로 만들어 줘.

가이드 = 함께 붙여넣은 "Hanji Traditional" 디자인 가이드 참조.

[주제]
예: "체험형 전시 상설관 기획안" / "지역 축제 기획 제안" / "문화재 활용 프로그램"

[문서 정보]
- 제목 (두 줄로 끊기면 더 좋음 — 둘째 줄이 적색으로 강조됨)
- 한 줄 설명
- 발주처 / 연도

[내용 — 있는 만큼만]
- 기획 배경 (왜 지금 이것을 하는가)
- 이야기 · 콘셉트 구조 (관람객이 무엇을 경험하는가)
- 공간 · 프로그램 구성 (구역명 - 연출 - 면적 - 체류시간)
- 운영 계획 (일정 · 인력 · 예산 구조)
- 기대 효과

[요구]
- 한지 배경 #F2EADB + 먹 #1F1B16, 액센트는 적 #A8342A · 청 #2B5A7E · 황 #C8A02E 중
  **슬라이드당 한 색만**
- 배경은 CSS 겹치기로 한지 질감 (radial-gradient + repeating-linear-gradient 2겹)
- 제목·목차 숫자·표 머리 = Nanum Myeongjo (세리프) / 본문 = Pretendard (고딕)
- 표지 = 자간 넓은 소제목 → 큰 명조 제목(둘째 줄 적색) → 굵은 먹선 → 부제 + 오른쪽 적색 낙관 사각
- 목차 = 한자 숫자 壹 貳 參 肆 伍 陸, 2열, 항목마다 얇은 먹선
- 이미지 자리 = 먹선 프레임 + 안쪽 여백. 사진 없으면 원·반원 도형으로 형태만 (달·능선)
- 표 = 배경색 없이 먹선만. 위 2px / 아래 1px / 행 사이 14% / 마지막 행 2px
- 기와·단청·태극 문양 X · 그라디언트 배경 X · 그림자 X · 둥근 모서리 X · 이모지 X
- 여백을 넉넉히 (채우지 않는 것이 이 톤의 격)

[형식]
- HTML 1파일 stacked · 1920×1080 · 슬라이드 4~6장
- 각 슬라이드 위·아래 얇은 먹선 머리말·꼬리말
