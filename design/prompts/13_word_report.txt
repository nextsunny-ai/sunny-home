다음 디자인 가이드를 따라 워드형 보고서를 인쇄용 HTML로 만들어 줘.

가이드 = 함께 붙여넣은 "Word Report" 디자인 가이드 참조.

[주제]
예: "OOO 인수 검토 보고서" / "OOO 시장 조사 보고서" / "OOO 사업 검토 보고서"

[문서 정보 — 표지에 들어감]
- 제목 / 부제
- 한 줄 설명 (무엇을 다루는 문서인가)
- 작성자 · 소속 / 버전 / 일자 / 분류(대외비 여부) / 범위

[내용 — 있는 만큼만 주면 됨]
- 대상 개요 (표로 들어갈 항목·값)
  예) 회사명 / 설립 / 대표 / 사업 / 인력 / 매출 / 자산
- 연혁 (시기 - 내용)
- 구조 설명 (수익구조 · 원가구조 · 운영 방식 등)
- 숫자 (지표 - 수치, 추정치는 "추정"이라고 표시)
- 쟁점별 판정 (쟁점 - 판정 - 근거)
- 결론 · 검토 의견
- 다음 단계

[요구]
- 흰 종이 + 무채색만 (검정 #111111 · 본문 #242424 · 회색 #767676 / #9A9A9A / #E3E3E3 / #F5F5F5)
- 액센트 컬러 X · 이모지 X · 아이콘 X · 둥근 모서리 X · 그림자 X
- 표지 = 자간 넓은 영문 라벨 → 굵은 검정 가로선 → 큰 제목 → 부제 → 얇은 선 → 메타 목록
- 큰 단락은 검정 PART 바 (흰 글씨), 섹션은 `01  제목` 통번호 + 회색 밑줄
- 구조화된 사실은 전부 표로. 표 = 검정 헤더(흰 글씨) · 짝수행 #F5F5F5 · 세로선 없음 · 위아래만 굵은 선
- 판단·결론은 회색 배경 + 왼쪽 검정 바 인용 박스에 (섹션당 1개까지)
- 불릿은 em dash(—), 순서 있으면 숫자
- 푸터 = 좌(문서명·분류) 중(작성자·소속) 우(페이지번호)
- 사실과 판단을 섞지 말 것. 추정치는 "(추정)" 표기
- 영업 톤 형용사 금지 — 숫자와 사실로만

[형식]
- HTML 1파일. 페이지마다 <section class="page">
- Letter 8.5×11in 세로 · 여백 상하 0.90in / 좌우 0.97in
- @page { size: Letter; margin: 0 } + .page { break-after: page } 넣어서
  Chrome Ctrl+P → PDF 저장하면 바로 문서가 되게

출력 = HTML 코드만.
