# Storyboard · Film Plan — 디자인 가이드

영상 · 애니메이션 · 광고 · 트레일러의 **콘티와 연출 기획서**.
보여주는 것이 아니라 **작업 지시서**다. 예뻐 보이는 것보다 읽고 그대로 찍을 수 있는 것이 우선이다.

## 폰트
- 본문 · 제목 = Pretendard
- 번호 · 시간 · 렌즈 · 라벨 = **JetBrains Mono** (숫자가 줄 맞아야 한다)
- 모노는 자간 0.12~0.28em · 영문 대문자

## 컬러
```
워크시트 배경   #F4F4F2
카드 · 시트     #FFFFFF
테두리          #D9D9D4
안쪽 선         #EBEBE7
텍스트          #1A1A1A
보조 텍스트      #7A7A74
액센트          #2F6B63   (필름 그린 — 시간·컷수·강조에만)
컷 프레임 바탕   #E7E7E2
슬레이트        #1A1A1A + 흰 글자
```
액센트는 **숫자에만** 쓴다. 문장에는 쓰지 않는다.

## 레이아웃
- 1920×1080 + 패딩 52px 72px
- 위·아래 모노 바 (좌 = 지금 무엇을 보는 중인지 / 우 = 범위·페이지)
- 상단 바 왼쪽에 9×9px 액센트 사각 하나

## 구성 요소

### 슬레이트 (표지 오른쪽)
검정 박스 + 위쪽 흑백 교차 줄무늬 6칸 + 아래 메타 행
(TITLE · FORMAT · RUNTIME · SCENES · DIRECTOR). 값 중 숫자만 민트 `#7FD1C5`.

### 씬 리스트
표 = SC · 장소 · 시간 · 컷 · 길이 · 핵심.
SC·시간·컷·길이는 모노. 컷 수만 액센트 색.
표 아래 요약 3칸 (총 컷수 · 러닝타임 · 로케이션 수).

### 콘티 시트 (핵심)
- 3열 그리드 · 각 칸 = 흰 카드 1px 테두리
- 위 = **16:9 프레임** (바탕 #E7E7E2), 왼쪽 위에 검정 컷 번호 배지
- 아래 = 앵글(WIDE · CLOSE · O.S. · PAN → · TWO SHOT · EMPTY) 좌측, 초수 우측(액센트)
- 그 아래 한 줄 설명 — **무엇을 보여주는가**만. 감상 X

### 프레임 안 구도 표시
그림을 그리지 않는다. 도형으로 위치만 잡는다.
- 하늘/지면 = 상하 2분할 + 1px 지평선
- 인물 = 위가 둥근 세로 막대 (크기로 원근, opacity로 앞뒤)
- 시선·이동 = 액센트 선 + 삼각 화살촉
- 강조 대상 = 액센트 테두리 사각

### 컷 상세
왼쪽 큰 프레임 + 오른쪽 스펙 시트
(LENGTH · LENS · MOVE · LIGHT · SOUND · NOTE). 라벨은 모노 대문자, 값은 한 줄 문장.

## 문체
- 지시문으로 쓴다. "~한다 · ~하지 않는다"
- 초 단위를 반드시 적는다
- 감정 형용사 X ("아름답게 · 감동적으로") → 카메라·빛·소리로 적는다

## 금기
- 다크 배경 X (작업 중 인쇄해서 쓰는 문서다)
- 액센트 2색 이상 X
- 프레임 안에 일러스트 X (구도만)
- 이모지 X · 그림자 X · 둥근 모서리 X

## 출력 형식
4~6장 stacked HTML · 1920×1080. 인쇄해서 현장에서 쓰므로 흰 바탕을 유지한다.
