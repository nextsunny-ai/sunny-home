# Hanji Traditional — 디자인 가이드

전통문화 · 사극 IP · 문화재 · 지자체 · 축제 제안. 한지 위에 먹으로 쓴 톤.
색은 오방색에서 세 개만 빌려 쓴다. 많이 쓰면 촌스러워진다.

## 폰트
- 제목 · 숫자 = **Nanum Myeongjo** (또는 Noto Serif KR) — 세리프가 이 톤의 핵심
- 본문 = Pretendard (고딕이어야 읽힌다. 본문까지 명조로 하지 않는다)
- 라틴 대문자는 자간을 넓게 (0.2~0.42em)

## 컬러
```
한지 배경     #F2EADB
한지 그늘     #EAE0CE   (슬라이드 바깥 · 여백)
먹            #1F1B16
먹 60%        rgba(31,27,22,0.60)   본문
먹 35%        rgba(31,27,22,0.35)   캡션
먹 14%        rgba(31,27,22,0.14)   구분선
적 (낙관)     #A8342A
청            #2B5A7E
황            #C8A02E
```
액센트는 **한 슬라이드에 한 색만**. 적·청·황을 한 화면에 다 쓰지 않는다.

## 배경 (한지 질감)
평평한 단색 대신 세 겹을 겹친다 — 이미지 없이 CSS만으로.
```
radial-gradient(120% 90% at 15% 0%, rgba(255,255,255,.55), transparent 55%),
repeating-linear-gradient(90deg, rgba(31,27,22,.030) 0 1px, transparent 1px 7px),
repeating-linear-gradient(0deg,  rgba(31,27,22,.022) 0 1px, transparent 1px 9px),
#F2EADB
```

## 레이아웃
- 1920×1080 + 패딩 64px 88px
- 위·아래에 얇은 먹선(1px 14%) 머리말·꼬리말
- 머리말 = 명조 + 자간 0.42em (`기 획 제 안` 처럼 글자 사이를 띄운다)
- 여백을 넉넉히. 채우지 않는 것이 이 톤의 격이다

## 타이포
- 표지 제목 = 명조 800 · 150px · line-height 1.06 (두 줄, 둘째 줄만 적색)
- 표지 아래 굵은 먹선 190×3px
- 섹션 제목 = 명조 46~62px
- 본문 = Pretendard 22px · line-height 1.85
- 캡션 = 15px · 먹 35%

## 구성 요소

### 낙관 (도장)
168×168px 적색 정사각 + 흰 명조 글자 2줄. 표지 오른쪽에 하나만.
둥근 모서리 X. 그림자 X.

### 목차
한자 숫자 `壹 貳 參 肆 伍 陸` + 황색. 2열 × 3행. 각 항목 아래 얇은 먹선.

### 이미지 자리 (먹 프레임)
1px 먹선 테두리 + 안쪽 여백 18px + 반투명 흰 바탕.
사진이 없을 때는 달·능선처럼 **형태만** 도형으로 (원 + 반원). 그림 그리지 않는다.

### 태그
사각 테두리 1px + 여백 9px 20px. 둥근 모서리 X. 색은 적 또는 청 하나만.

### 표
- 머리 = 명조 · 위 2px 먹선 · 아래 1px 먹선
- 행 = 아래 1px 먹 14% / 마지막 행만 2px 먹선
- 배경색 채우기 X (한지 바탕을 살린다)

### 주석
왼쪽 3px 적색 세로선 + 먹 60% 텍스트. 추정·기준을 밝히는 자리.

## 금기
- 기와·단청·태극 문양 이미지 X (촌스러워진다 — 색과 여백으로만)
- 그라디언트 배경 X · 그림자 X · 둥근 모서리 X
- 이모지 X
- 본문 명조 X (제목만)
- 오방색 다섯 색 동시 사용 X
