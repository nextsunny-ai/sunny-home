# Hanji Traditional — 디자인 가이드

전통문화 · 사극 IP · 문화재 · 지자체 · 축제 제안. 한지 위에 먹으로 쓴 톤.
색은 오방색에서 세 개만 빌려 쓴다. 많이 쓰면 촌스러워진다.

## 폰트
- 제목 · 숫자 = **Nanum Myeongjo** (또는 Noto Serif KR) — 세리프가 이 톤의 핵심
- 본문 = Pretendard (고딕이어야 읽힌다. 본문까지 명조로 하지 않는다)
- 라틴 대문자는 자간을 넓게 (0.2~0.42em)

## 컬러
```
한지 배경     #F2EADB
한지 그늘     #EAE0CE   (슬라이드 바깥 · 여백)
먹            #1F1B16
먹 60%        rgba(31,27,22,0.60)   본문
먹 35%        rgba(31,27,22,0.35)   캡션
먹 14%        rgba(31,27,22,0.14)   구분선
적 (낙관)     #A8342A
청            #2B5A7E
황            #C8A02E
```
액센트는 **한 슬라이드에 한 색만**. 적·청·황을 한 화면에 다 쓰지 않는다.

## 배경 (한지 질감)
평평한 단색 대신 세 겹을 겹친다 — 이미지 없이 CSS만으로.
```
radial-gradient(120% 90% at 15% 0%, rgba(255,255,255,.55), transparent 55%),
repeating-linear-gradient(90deg, rgba(31,27,22,.030) 0 1px, transparent 1px 7px),
repeating-linear-gradient(0deg,  rgba(31,27,22,.022) 0 1px, transparent 1px 9px),
#F2EADB
```

## 레이아웃
- 1920×1080 + 패딩 64px 88px
- 위·아래에 얇은 먹선(1px 14%) 머리말·꼬리말
- 머리말 = 명조 + 자간 0.42em (`기 획 제 안` 처럼 글자 사이를 띄운다)
- 여백을 넉넉히. 채우지 않는 것이 이 톤의 격이다

## 타이포
- 표지 제목 = 명조 800 · 150px · line-height 1.06 (두 줄, 둘째 줄만 적색)
- 표지 아래 굵은 먹선 190×3px
- 섹션 제목 = 명조 46~62px
- 본문 = Pretendard 22px · line-height 1.85
- 캡션 = 15px · 먹 35%

## 구성 요소

### 낙관 (도장)
168×168px 적색 정사각 + 흰 명조 글자 2줄. 표지 오른쪽에 하나만.
둥근 모서리 X. 그림자 X.

### 목차
한자 숫자 `壹 貳 參 肆 伍 陸` + 황색. 2열 × 3행. 각 항목 아래 얇은 먹선.

### 이미지 자리 (먹 프레임)
1px 먹선 테두리 + 안쪽 여백 18px + 반투명 흰 바탕.
사진이 없을 때는 달·능선처럼 **형태만** 도형으로 (원 + 반원). 그림 그리지 않는다.

### 태그
사각 테두리 1px + 여백 9px 20px. 둥근 모서리 X. 색은 적 또는 청 하나만.

### 표
- 머리 = 명조 · 위 2px 먹선 · 아래 1px 먹선
- 행 = 아래 1px 먹 14% / 마지막 행만 2px 먹선
- 배경색 채우기 X (한지 바탕을 살린다)

### 주석
왼쪽 3px 적색 세로선 + 먹 60% 텍스트. 추정·기준을 밝히는 자리.

## 금기
- 기와·단청·태극 문양 이미지 X (촌스러워진다 — 색과 여백으로만)
- 그라디언트 배경 X · 그림자 X · 둥근 모서리 X
- 이모지 X
- 본문 명조 X (제목만)
- 오방색 다섯 색 동시 사용 X

## 5장 패턴 (표준 구성)
1. **표지** — 풀블리드 먹 산수 배경 위에 제목. 아래 참조
2. **목차** — 한자 숫자 6항목 2열 + 오른쪽 세로 편액
3. **연출 구성** — 4분할 카드. 각 칸에 서로 다른 색조의 장면 + 이름 · 시간 · 한 줄
4. **공간 구성** — 왼쪽 평면도 라인 드로잉 + 오른쪽 표 + 주석
5. **운영 계획** — 간트 일정 바 + 예산 비중 바

## 표지 산수 배경 (이미지 없이 CSS만)
겹치는 순서가 곧 원근이다. 뒤에서 앞으로 쌓는다.
```
1) 밤하늘   linear-gradient(180deg, #16130F, #241E17 42%, #3A3025 72%, #574733)
2) 달       원 + box-shadow 두 겹으로 후광 (blur 대신 shadow가 깨끗하다)
3) 새       border-top 2px + border-radius 50% 짜리 납작한 곡선 3개, 크기·투명도를 다르게
4) 능선     border-radius: 50% 50% 0 0 인 넓은 타원 5겹
            뒤로 갈수록 투명도를 낮추고(0.22 → 0.74 → 불투명) 좌우 위치를 엇갈리게
5) 안개     흰색 세로 그라디언트 띠 + blur(2px), 능선 사이에 2줄
6) 한지 결   배경 위에 repeating-linear-gradient 두 겹을 덧입힘 (밝은 색 · 낮은 투명도)
```
제목은 이 위에 `#F4EEDF` 로 얹고 `text-shadow` 로 띄운다. 머리말·꼬리말 선은 밝은 색으로 바꾼다.

## 4분할 장면 카드
칸마다 시간대를 색으로 구분한다 — 그림을 그리지 않고 색조 + 도형 2~3개로만.
```
초저녁  갈색 계열 + 등불(둥근 사각 + 노란 box-shadow)
골목    어두운 회갈 + 세로 벽 띠 + 빛줄기 그라디언트
강가    푸른 계열 + 아래쪽 물빛 면 + 수평 잔물결 선 3개
새벽    보라→살구 + 가운데 radial-gradient 여명
```
인물은 위가 둥근 세로 막대. 크기와 투명도로 원근을 만든다.

## 평면도
한지 위 먹선. 사각형 4개를 붙여 배치하고 각 칸에 한자 번호 + 용도 · 면적.
동선은 붉은 점선, 입구는 붉은 원. 우하단에 `SCALE 1 : 200`.

## 일정 · 예산
- 간트 = 6칸 그리드 · 막대 높이 10px. 진행 = 먹, 콘텐츠 = 황, 개관 = 적
- 예산 = 항목명 + % + 아래 가로 막대. 색은 먹 → 먹 72% → 황 → 먹 35% 순으로 내린다
