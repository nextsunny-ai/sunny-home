# Word Report — 디자인 가이드

워드(문서형) 보고서 표준. 슬라이드가 아니라 **A4/Letter 세로 문서**다.
색은 검정·회색만 쓴다. 액센트 컬러 없음. 정보가 주인공이고 디자인은 뒤로 물러난다.

용도 = 인수 검토 · 사업 검토 · 시장 조사 · 내부 보고 · 실사 보고

## 폰트
- 본문 = Pretendard (없으면 맑은 고딕 · Noto Sans KR)
- 굵은 곳 = Pretendard SemiBold
- 표지 제목만 = Pretendard Black
- 모노스페이스 X · 세리프 X

## 컬러 (전부 무채색)
```
종이 배경     #FFFFFF
본문          #242424
제목 · 강조    #111111
인용 텍스트    #303030
라벨 · 부제    #767676
섹션 번호      #9A9A9A
얇은 구분선    #E3E3E3
표 짝수행 · 인용 배경   #F5F5F5
표 헤더 배경 · PART 바  #111111  (글자 흰색)
```

## 페이지
- Letter 8.5 × 11in 세로 (A4로 바꿔도 됨)
- 여백 = 상하 0.90in · 좌우 0.97in
- 줄간격 1.6 안팎 · 문단 사이 여백은 좁게

## 글자 크기 (pt)
| 요소 | 크기 | 굵기 · 색 |
|---|---|---|
| 표지 제목 | 42 | Black · #111111 |
| 표지 부제 | 21 | SemiBold · #111111 |
| 표지 상단 라벨 | 8.5 | 자간 0.34em · #767676 |
| 표지 서브라인 | 11.5 / 9.5 | #767676 / #9A9A9A |
| PART 바 | 15 | SemiBold · 흰색 |
| 섹션 번호 | 14 | SemiBold · #9A9A9A |
| 섹션 제목 | 12.5 | SemiBold · #111111 |
| 본문 | 10.5 | #242424 |
| 표 | 9.5 | #242424 |
| 캡션 · 푸터 | 8~9 | #9A9A9A |

## 구성 요소

### 표지
상단 라벨 (자간 넓은 영문 대문자) → **굵은 검정 가로선 2.75pt** → 큰 제목 → 부제 →
서브라인 2줄 → 얇은 회색선 → 메타 목록 (작성 · 버전 · 일자 · 분류 · 범위).
메타는 라벨 회색 9pt + 값 SemiBold 10pt 2단 정렬.

### PART 바
검정 띠에 흰 글씨. 페이지 폭 전체. 큰 단락(조사 / 판단 / 부록)을 나눌 때만 쓴다.

### 섹션 제목
`01  회사 개요` — 번호는 연회색, 제목은 검정. 아래 **0.75pt #E3E3E3 밑줄**.
번호는 문서 전체 통번호(01, 02, 03…)로 이어간다.

### 표 (구조화된 사실은 전부 표로)
- 위·아래 = 1pt #111111 굵은 선 / 행 사이 = 0.25pt #E3E3E3 / **좌우 세로선 없음**
- 헤더 행 = 검정 배경 + 흰 글씨 SemiBold, 왼쪽 정렬
- 짝수 행 = #F5F5F5 (지브라)
- 숫자 열은 오른쪽 정렬 + tabular-nums

### 인용 · 판단 박스
회색 배경 #F5F5F5 + **왼쪽 검정 세로 바 4px** + 이탤릭.
사실이 아니라 **판단·결론**을 담는 자리다. 한 섹션에 1개까지.

### 리스트
- 불릿 = em dash `—` (점·아이콘 X)
- 순서가 있으면 `1.` 숫자, 번호는 검정 SemiBold

### 푸터
좌 = 문서명 v0.0 · 분류 / 중 = 작성자 · 소속 / 우 = 페이지 번호. 8pt 연회색.

## 문체
- 개조식 종결 (~함 · ~임) 또는 평서 단문. 둘 중 하나로 통일한다.
- 사실과 판단을 섞지 않는다. 판단은 인용 박스나 「검토 의견」 섹션에.
- 추정치는 `(추정)` `(공개 자료 기준)`을 붙인다.

## 금기
- 액센트 컬러 X (파랑·빨강 포함 — **무채색만**)
- 이모지 X · 아이콘 X · 그림자 X · 둥근 모서리 X
- 그라디언트 X · 배경 이미지 X
- 영업 톤 형용사 X ("혁신적 · 획기적 · 최고의")
- 표 세로선 X · 표 전체 테두리 박스 X

## 6쪽 패턴 (표준 구성)
1. **표지**
2. PART 1 + 개요 표 + 한 줄 요약 + 조직 + 연혁 표
3. 수익 구조 (리스트 + 표 + 인용) + 원가 구조 + 재무 개요 표
4. PART 2 + 쟁점 판정 표 + 검토 의견 + 다음 단계 표
5. 시장 (표 + 인용) + 경쟁 (표 + 마무리 문단)
6. 전제 조건 표 + 자료 출처 + 용어 표

## 페이지를 채운다
문서는 **쪽마다 8할 이상 채워야** 완성된 것으로 읽힌다 (표지 제외).
아래가 비면 내용을 늘리는 것이 아니라 **다음 쪽 내용을 끌어올린다.**
한 쪽에 표 1~2개 + 문단 2~3개 + 리스트 1개 정도가 적정 밀도다.

## 출력 형식
인쇄용 HTML 1파일 (페이지 단위 `<section class="page">` 반복).
`@page { size: Letter; margin: 0 }` + `.page { break-after: page }` 를 넣어
Chrome `Ctrl+P` → PDF 저장하면 그대로 문서가 된다.
워드(.docx)가 필요하면 같은 위계(제목 색·크기·표 스타일)를 유지한 채 변환한다.
